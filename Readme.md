# WordPress MCP (Deprecated)

**This repository is deprecated and archived. It is no longer maintained, and it is not the recommended way to add MCP support to WordPress.**

**For current setup instructions and documentation, see [developer.wordpress.com/docs/mcp](https://developer.wordpress.com/docs/mcp/).**

Ongoing development happens in these projects:

- [mcp-adapter](https://github.com/WordPress/mcp-adapter): the canonical plugin and Composer package for MCP integration in WordPress.
- [Abilities API](https://github.com/WordPress/abilities-api): moving into WordPress Core as of version 6.9.

The code in this repository remains available for historical reference only. Do not use it for new installations.
